# Contributing

Thanks for looking. Bug reports and false-positive reports are the most
useful things you can send: say what the client was, what the gateway did,
and the visit id from the log or the weekly report. Leave out visitors'
addresses and other personal data.

## Code

Veritell is licensed under the [AGPL-3.0](LICENSE). A commercial edition
may be offered alongside it, so every code contribution needs a signed
Contributor Licence Agreement before it can be merged. The CLA isn't
published yet. Until it is, please open an issue before writing code.

## Security

Please don't open public issues for vulnerabilities or detection bypasses.
Report them privately: see [SECURITY.md](SECURITY.md).
